# 🌍 Python Translator

**Version:** 1.5.9
**Developer:** SOVKEN LLC

## Description

Python Translator — приложение для перевода текста с использованием Google Translate.

## Features

* Перевод текста
* Поддержка различных языков
* Простой интерфейс
* Быстрая работа

## Requirements

* Python 3.8+
* googletrans

## Installation

```bash
pip install googletrans
```

## Launch

```bash
python google_translate_color.py
```
